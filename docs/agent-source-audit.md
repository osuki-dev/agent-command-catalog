## Recommended order

Start with `copilot`, `droid`, `kilo`, `qwen`, `pi`, and `omp`: they have explicit first-party built-in command listings and clear package or release paths. `mastracode`, `kimi`, `devin`, `cursor`, and `antigravity` also have first-party listings but need more care around versioning, product transitions, or conditional commands. Hold `grok` until the integration-to-product mapping is verified. Keep each JSON file at one latest version, consistent with the repository's current design.
